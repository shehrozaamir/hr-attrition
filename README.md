# HR Employee Attrition Prediction

A Machine Learning project focused on analyzing and predicting employee attrition using HR data.

## About
This project explores employee attrition patterns through Exploratory Data Analysis (EDA) and Machine Learning. It uses classification techniques to predict whether an employee is likely to leave the organization.

SHAP is used to understand model predictions, while FastAPI connects the trained model to a simple interactive web interface.

## Technologies Used
- Python
- Pandas & NumPy
- Scikit-learn
- SHAP
- FastAPI
- HTML, CSS & JavaScript

## Key Features
- Exploratory Data Analysis
- Employee Attrition Prediction
- Model Evaluation & Threshold Optimization
- SHAP-based Model Explainability
- Interactive Web Interface
